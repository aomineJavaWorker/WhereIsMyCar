# Hanojas Tornis

Готовая сцена: `Assets/Scenes/HanojasTornis.unity`. Версия Unity: **6000.0.49f1**.
Сцена, объекты UI, четыре диска, три стержня, события кнопок и ссылки сохранены
редактором Unity. Запускать генератор после получения файлов не требуется.

## Управление

Нажмите на диск или область стержня, чтобы выбрать его верхний диск. Затем нажмите
на другой стержень. Повторное нажатие на исходный стержень отменяет выбор.
Больший диск нельзя положить на меньший; неудачная попытка не меняет башни и счётчик.
Цель — перенести четыре диска на третий стержень. Минимум — 15 ходов.
Restart и Spēlēt vēlreiz сбрасывают игру; обе кнопки меню возвращают в MainMenu.

В главном меню StartButton по-прежнему открывает CityScene, HanojasButton открывает
HanojasTornis, ExitButton закрывает приложение. Существующие подписи Start/Exit
на латышском сохранены.

## Android и реклама

CanvasScaler масштабирует UI по меньшей стороне экрана, MobileUISafeArea учитывает
вырезы и системные отступы. Диски пересчитывают геометрию при изменении размера поля;
поворот экрана не сбрасывает состояние игры. Стержни являются крупными UI-кнопками;
декоративные диски и тексты не перехватывают нажатия.

В новую сцену скопирован существующий AdsScriptHolder с текущими ID и test mode.
AdManager сохраняется между сценами; копия при повторном входе отключается перед
инициализацией её компонентов. Автоматические interstitial сохранены. BannerAd
автоматически показывается только в CityScene. RewardedAds и его перезарядка
15 секунд не переписаны. Шрифт HanojasSans создан из имеющегося LiberationSans.ttf
и содержит латышские символы; существующий TMP fallback не заменён.

## Воспроизводимые проверки

Меню Unity: **Tools → Where Is My Car → Validate Hanojas Integration**.
Проверяется граф из 81 состояния, минимальное решение за 15 ходов, недопустимые
перемещения, счётчик, выделение, победа, рестарт, ссылки сцен и события кнопок,
наличие существующих автомобилей, семи мобильных контролов, HUD и адаптивного UI.
Геометрия новой сцены проверяется для портретного, альбомного, широкого и квадратного
экранов с отступами safe area.

Batchmode (замените пути на свои; проект должен быть закрыт либо используйте его копию):

```powershell
& $unity -batchmode -nographics -quit -projectPath $project -executeMethod HanojasProjectChecks.Validate -logFile checks.log
& $unity -batchmode -projectPath $project -executeMethod HanojasPlayChecks.RunBatch -logFile play.log
& $unity -batchmode -nographics -quit -buildTarget Android -projectPath $project -executeMethod HanojasProjectChecks.BuildAndroid -logFile build.log
```

У Play Mode-проверки нет флага `-quit`: она завершает Unity сама. Это batch-команда
для отдельной копии, не команда для открытой пользовательской сессии. Она проверяет
реальные события кнопок, попадание нажатия по диску, переходы между сценами,
drag-and-drop автомобиля, поворот, изменение размеров обеих осей, flip, победу,
поражение, жизни и рестарт CityScene. Проверяет блокировку баннера и повторную
готовность rewarded после 15 реальных секунд. Автоматический показ SDK в этом
тесте подавлен; доставка рекламы по сети этим тестом не подтверждается.
Превью сохраняются в `Builds/Previews`.

APK создаётся в `Builds/Android/WhereIsMyCar-HanojasTornis.apk`. BuildPipeline должен
завершиться с `Succeeded`; каталог Builds и APK исключены из Git. Генератор
`SetupHanojasTornis.Create` оставлен для воспроизводимости и перестраивает сцену
с меню; при обычном открытии готового проекта запускать его не нужно.

## Проверка на телефоне

1. Открыть обе игры из меню, вернуться и повторить; проверить Exit на устройстве.
2. Повернуть телефон при выбранном диске и при открытом окне победы; проверить
   safe area, читаемость, нажатия и отсутствие перекрытий в обеих ориентациях.
3. Проверить жесты перетаскивания автомобилей, удержание кнопок трансформации,
   таймер, звёзды, победу и поражение CityScene.
4. При доступной рекламе проверить interstitial при смене сцены, rewarded только
   по нажатию и повторно через 15 секунд, скрытие/возврат баннера в CityScene.
   Баннер не должен появляться в меню и Hanoi, включая поздний callback загрузки.
5. Повторить переходы и игру без интернета; ошибки SDK не должны блокировать UI.
6. Проверить сворачивание/возобновление игры и смену ориентации после рекламы.

Для GitHub Release нужно опубликовать исходники в существующую ветку `android`,
создать релиз для соответствующего коммита и прикрепить APK как release asset,
не добавляя APK в Git.
